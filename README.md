## 🚀 Run Locally

No framework or package installation is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/shoyabsadik/shoyabsadik.github.io.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

> If your repository uses a different name, replace `shoyabsadik.github.io` in the clone command with your actual repository name.

## 🌐 Deployment

This website can be hosted using **GitHub Pages**.

1. Push the website files to your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your deployment branch (usually `main`) and the root folder (`/`).
5. Save and wait for GitHub Pages to publish the site.

For a user site repository named `shoyabsadik.github.io`, the website is typically available at:

**https://shoyabsadik.github.io/**
